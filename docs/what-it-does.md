# What it does

- **Reads and edits your code.** Not "here's how you'd do it" — it opens the
  file, changes it, and tells you what it touched.
- **Runs commands.** With your approval, and confined to your workspace.
- **Remembers.** Conversations are saved, so a session survives a restart,
  and the notes of the days that have passed are sorted into what is worth
  keeping.
- **Learns the job.** A skill is a written procedure it loads when a task
  needs one, and memory keeps the facts worth keeping — each tagged with
  where it came from.
- **Borrows other tools.** MCP servers offer their own tools, and they are
  offered to the model alongside the built-in ones.
- **Looks things up.** It searches the web, reads the page it finds, and
  tells you what is there.
- **Sees pictures.** A screenshot or a photograph can be sent to it — in a
  chat, in the terminal, or over the gateway — and it answers about it.
- **Hears and speaks.** It can take a voice command and answer out loud,
  with the microphone shut while it is talking so it does not answer
  itself.
- **Keeps a plan.** Work that takes more than a step is written down and
  ticked off, so you can see what it is doing and what is left.
- **Hands work over.** Some jobs would drown the conversation, so the
  assistant gives them to another one and takes back the answer.
- **Keeps its promises.** "Check the build every half hour" is taken, kept,
  and answered in the chat that asked for it.
- **Keeps answering.** When a model goes down or runs out of credit, the
  next one in the list is asked instead.
- **Comes to you.** The gateway exposes the same agent over HTTP and
  WebSocket, so a Telegram, Discord, Slack or WhatsApp bot, or another
  program, can drive it.
- **Lets people in carefully.** A stranger on a chat platform is given a
  code, and only works once the owner approves it.
